AI that understands people

Plain English in, item-by-item split out

Gemini turns a messy receipt photo into structured data, then reads your sentence and decides who shares each item, with a reason you can check.

  • Reads any receipt photo, not just templates
  • Understands "didn't drink", "only for", "shared by"
  • Shows its reasoning next to every item
  • Foreign receipts are converted to the trip currency

Code counts the money

The AI never decides an amount

All money math is plain, tested Python in whole cents. Tax and tip are shared in proportion, and the shares always add up exactly to the receipt.

Safe by design

Checks before any money moves

AI can make mistakes, so every answer is checked, and you can always cross-check it yourself.

Blurry photo check

A plain image-sharpness check asks for a clearer photo. If the AI isn't sure, the receipt is rejected, not guessed.

Check & fix

Compare with the photo, correct any item, tax or total, and the code recalculates the shares. It's marked "Checked by you".

Totals must match

Items + tax + tip are compared to the receipt total. Low confidence and unknown names show warnings.

Prompt-injection safe

Text on a receipt is treated as data only. Instructions hidden in it are ignored.

Server-side PayPal

The server checks that the debt exists, creates the PayPal order for the exact amount, and captures it after approval.

Works without keys

Demo mode runs offline with sample receipts, so anyone can try it in a minute.
